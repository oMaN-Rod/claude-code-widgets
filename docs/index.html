claude-code-widgets

Small cards that sit beside your Claude Code session, each one its own mod behind a slash command. of them, from a context meter and git status to a pixel crab, a dungeon crawl and Tetris. Every card below is the real widget, running in your browser against a simulated session. Pick one to open it on the workbench, where you can type its slash commands, run a turn to give it some work, or take the keys of a game.
